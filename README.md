# Music Player

Простое и функциональное Android-приложение для прослушивания локальных аудиофайлов. Проект построен с использованием современных подходов к разработке, включая Clean Architecture и библиотеку ExoPlayer.

## 🚀 Особенности

*   **Локальное воспроизведение:** Выбор и воспроизведение аудиофайлов прямо с устройства.
*   **Управление плейлистом:** Добавление нескольких треков одновременно, сохранение плейлиста между запусками приложения.
*   **Извлечение метаданных:** Автоматическое отображение названия трека, исполнителя и обложки альбома (если они есть в файле).
*   **Умное состояние:** Индикация текущего состояния трека (активный, играет, на паузе).
*   **Безопасный доступ:** Использование Storage Access Framework (SAF) для получения долгосрочного доступа к файлам.

## 🏗 Архитектура

Проект организован по принципам многослойной архитектуры (Clean Architecture), что обеспечивает легкость тестирования и поддержки:

*   **`domain`**: Содержит бизнес-логику и интерфейсы. Центральное звено — `PlaylistManager`, определяющий правила работы с треками.
*   **`data`**: Реализация хранения и обработки данных. `PlaylistManagerImpl` отвечает за извлечение метаданных через `MediaMetadataRetriever` и сохранение списка через `SharedPreferences`.
*   **`ui`**: Слой интерфейса, разделенный по фичам:
    *   `main`: Входная точка приложения (`MainActivity`).
    *   `playlist`: Экран со списком треков, реализованный через `Fragment`, `RecyclerView` и кастомный `Adapter`.

## 🛠 Технологический стек

*   **Язык:** [Kotlin](https://kotlinlang.org/)
*   **Audio Engine:** [ExoPlayer 2.19.1](https://exoplayer.dev/) — для стабильного и гибкого воспроизведения.
*   **UI Components:** 
    *   `RecyclerView` с кастомным `ViewHolder` для списка треков.
    *   `Material Design` (FloatingActionButton, CardView).
    *   `Fragments` для навигации.
*   **Persistence:** `SharedPreferences` + `PreferenceManager` для хранения URI плейлиста.
*   **Permission Handling:** Работа с `PersistableUriPermission` для доступа к файлам после перезагрузки устройства.

## 📦 Установка и запуск

1.  Клонируйте репозиторий.
2.  Откройте проект в **Android Studio (Bumblebee или выше)**.
3.  Дождитесь завершения Gradle Sync.
4.  Запустите приложение на эмуляторе или реальном устройстве (Android 5.0+).

## 💡 Использование

1.  Нажмите кнопку **"+"** (FloatingActionButton) на главном экране.
2.  Выберите один или несколько аудиофайлов из памяти устройства.
3.  Нажмите на иконку превью трека в списке, чтобы начать воспроизведение.
4.  Текущий играющий трек будет отмечен специальным индикатором.
